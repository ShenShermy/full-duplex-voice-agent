# =============================================================================
# requirements-gpu.txt —— 完整依赖（Windows + NVIDIA，4060 Ti 8 GB 卡调优过）
# -----------------------------------------------------------------------------
# 装法（不要直接 pip install -r，先看 setup/install_windows.ps1，它会按顺序处理）：
#     python -m pip install -r requirements-core.txt
#     python -m pip install torch==2.5.1 torchaudio==2.5.1 --index-url https://download.pytorch.org/whl/cu121
#     python -m pip install -r requirements-gpu.txt
#
# 【为什么 torch 要单独一行、单独用 cu121 源】
# PyPI 上的 torch 默认是 CPU 版（Windows 上），装完会发现 torch.cuda.is_available()
# 是 False —— 这是新手最容易踩的坑。必须用 download.pytorch.org/whl/cu121 这个源。
# RTX 4060 Ti 是 Ada 架构（sm_89），cu121 的 wheel 已经包含 sm_89 内核，能直接用。
#
# 【显存账本（8 GB）】
#     FunASR paraformer-zh + fsmn-vad + ct-punc   ≈ 1.5 GB
#     CosyVoice2-0.5B（fp16）                     ≈ 1.6 GB
#     Qwen2.5-7B-Instruct 4bit（可选，本地跑）      ≈ 5.0 GB
#     ------------------------------------------------------
#     只做「本地 ASR+TTS + LLM 走 API」          ≈ 3.5 GB    ✅ 舒服
#     全本地（含 7B-4bit）                       ≈ 8.5 GB    ⚠ 会 OOM，见 docs/04
#
# 所以默认配置是「LLM 走 API（或 llama.cpp 的 Q4_K_M，约 4.4 GB）」，
# 这是 8 GB 卡上最稳的组合。这不是妥协，是显存预算管理 —— 面试可以讲这个取舍。
# =============================================================================
